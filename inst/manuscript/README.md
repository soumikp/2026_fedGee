# Manuscript

- `main.tex`, `supplement.tex`, `references.bib`: submission sources.
- `main.pdf`, `supplement.pdf`: compiled submission.
- `tables/`: LaTeX tables generated by the scripts in `../simulations/` and
  `../application/`. Do not edit by hand.
- `figures/`: `visn_forest_paper.pdf` is Figure 1. The standalone version, with title and
  notes, is for presentations.

Tables 1–3 of `main.tex` are typed in; `../check_main_tables.R` checks them against the
script output. Compile with pdflatex, BibTeX, pdflatex, pdflatex, or run `../reproduce.sh`.
